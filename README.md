# 雨课堂工具助手 - 批量课件导出 | 课程归档

一个面向雨课堂的 Chromium 浏览器扩展，产品方向为“批量课件导出 | 课程归档”。

> 当前版本支持批量课件导出和课程归档。插件基于长江雨课堂开发，其他雨课堂平台不保证完全兼容。

## 功能概览

- 批量选择课程，将课堂课件导出为 PDF。
- 按日期和具体课件筛选导出内容。
- 支持一次授课包含多个课件，并按课件 ID 去重。
- 授权本地目录，以宽容或严格模式跳过重复文件。
- 识别普通、荷塘、黄河和长江雨课堂域名。
- 按自定义或学期关键词筛选旧课程，将课程移出首页并支持恢复。

## 安装

### Microsoft Edge

1. 下载并解压项目文件。
2. 打开 `edge://extensions/`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择包含 `manifest.json` 的仓库目录。

### Google Chrome

1. 下载并解压项目文件。
2. 打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的仓库目录。

代码更新后，请在扩展管理页面点击“重新加载”。首次导出时，需要选择并授权现有的“雨课堂课件”目录。

- 扩展不会绕过登录状态、课程权限或网站的内容保护。
- 导出的课件是网站打印流程生成的 PDF，不是原始 PPTX。
- 本项目是非官方工具，与雨课堂及其运营方无隶属或授权关系。
- 请仅归档和导出自己有权访问、保存和使用的内容。
