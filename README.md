# 长江雨课堂课件批量导出

一个用于[长江雨课堂](https://changjiang.yuketang.cn/)的浏览器扩展插件。插件复用网站已有的“课堂回顾 → 课件 → 打印课件”流程，将当前账号有权访问的课件批量导出为 PDF。

> [!IMPORTANT]
> 本项目导出的是网站提供的打印版课件（PDF），不是原始、可编辑的 `.ppt` 或 `.pptx` 文件。

## 功能

- 自动读取当前账号可访问的课程
- 批量选择课程并导出其中的课堂课件
- 正在浏览某门课程时，自动将该课程置顶并显示“当前页面”标记
- 支持一次授课包含多个课件，并按顺序分别导出
- 按课件 ID 合并重复引用，避免同一课程重复下载相同内容
- 显示扫描、导出、失败项目及重复引用数量
- 自动创建课程目录并生成便于整理的文件名
- 保留已经存在的文件，不静默覆盖旧文件

## 使用要求

- Microsoft Edge 或其他基于 Chromium 的浏览器
- 已登录 `changjiang.yuketang.cn`
- 当前账号本身具有课程和课件的访问权限
- 导出期间保持浏览器及登录标签页打开

扩展不会绕过登录、课程权限或网站的内容保护。

## 安装

### Microsoft Edge

1. 下载并解压项目文件。
2. 在地址栏打开 `edge://extensions/`。
3. 开启左侧的“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择包含 `manifest.json` 的 `yuketang-courseware-exporter` 文件夹。

### Chromium / Google Chrome

1. 下载并解压项目文件。
2. 在地址栏打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的 `yuketang-courseware-exporter` 文件夹。

代码更新后，请在扩展管理页面点击扩展的“重新加载”按钮。

## 使用方法

1. 登录[长江雨课堂](https://changjiang.yuketang.cn/)，并打开任意雨课堂页面。
2. 点击浏览器工具栏中的扩展图标。
3. 等待课程自动扫描完成。
4. 搜索并勾选需要导出的课程。
5. 点击“导出课件”。
6. 等待进度完成；PDF 会保存到浏览器的默认下载目录。

如果当前页面属于课程列表中的某门课程，该课程会出现在列表第一项，并带有“当前页面”标记。

## 输出目录与文件名

文件默认保存在以下结构中：

```text
浏览器下载目录/
└── 雨课堂课件/
    └── 课程名称/
        ├── 2026-09-01 第一次授课.pdf
        ├── 2026-09-08 第二次授课 - 课件 01 教学内容.pdf
        └── 2026-09-08 第二次授课 - 课件 02 课堂练习.pdf
```

- 单课件授课：使用日期和授课名称命名；课件标题不同时会附加课件标题。
- 多课件授课：使用 `课件 01`、`课件 02` 等编号保持顺序和文件名唯一。
- 文件已存在：浏览器会按自身规则生成重名后缀，例如 `(1)`，旧文件不会被覆盖。
- 文件名中的 Windows 非法字符会自动替换。

## 多课件与去重规则

| 情况 | 处理方式 |
| --- | --- |
| 一次授课包含多个不同课件 | 每个课件分别导出，并按出现顺序编号 |
| 同一授课时间线反复出现相同课件 ID | 合并为一个导出任务 |
| 同一课程的不同授课引用相同课件 ID | 只导出第一次扫描到的引用，并计入“重复引用” |
| 不同课程引用相同课件 ID | 每门课程分别保留一份 |
| 本地已有同名 PDF | 交由浏览器添加重名后缀，不覆盖旧文件 |

去重依据是网站返回的课件 ID，而不是文件名或 PDF 内容。

## 工作原理

扩展不会模拟逐节点击按钮，而是批量执行网站现有流程：

1. 使用当前登录会话读取课程列表。
2. 枚举课程中的课堂活动及课堂回顾。
3. 从课堂回顾中识别课件 ID。
4. 获取网站提供的打印课件数据。
5. 打开网站自身的打印页面并等待所有课件图片加载。
6. 调用 Chromium 的 `Page.printToPDF` 能力生成 PDF。
7. 将文件保存到对应课程目录。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `tabs` | 检查当前雨课堂标签页并创建临时打印页面 |
| `scripting` | 在已登录的雨课堂页面中调用网站接口、写入打印数据 |
| `downloads` | 将生成的 PDF 保存到浏览器下载目录 |
| `storage` | 保存导出进度、错误和任务状态 |
| `debugger` | 调用 Chromium DevTools Protocol 的 `Page.printToPDF` |
| `changjiang.yuketang.cn` | 访问课程、课堂回顾和打印页面 |
| `changjiang-private-qn.yuketang.cn` | 加载当前账号有权访问的课件图片 |

使用 `debugger` 权限时，浏览器可能短暂显示扩展正在调试页面的提示。这是调用浏览器 PDF 生成功能产生的正常提示，课件导出结束后扩展会立即断开调试连接。

## 常见问题

### 为什么导出的不是 PPTX？

网站的“打印课件”流程提供的是课件页面及图片，不提供原始 PPTX 文件。本扩展按照该流程生成 PDF，无法恢复原始动画、备注、字体或可编辑对象。

### 扫描不到课程怎么办？

请依次确认：

1. 当前活动标签页属于 `https://changjiang.yuketang.cn/`。
2. 页面没有退出登录，并能正常打开课程列表。
3. 扩展已在管理页面重新加载。
4. 当前账号确实有课程访问权限。

### 为什么某些授课没有导出文件？

可能原因包括：授课没有课件、课堂回顾尚未生成、账号无权访问、课件图片加载失败，或网站接口发生变化。扩展会在进度区域显示最近的失败原因。

### 导出过程中可以关闭弹窗吗？

可以关闭弹窗，但请保持浏览器和用于登录的雨课堂标签页打开。重新打开弹窗可以查看已保存的任务状态。

### 为什么导出需要较长时间？

每个课件都需要加载完整打印页面并等待所有图片完成，再逐个生成 PDF。课程和课件数量较多时，整个过程会相应变长。

## 隐私与安全

- 课程信息和课件不会上传到第三方服务器。
- 网络请求仅发往清单中声明的长江雨课堂域名。
- 扩展复用浏览器中现有的登录状态，不读取或保存账号密码。
- 所有导出结果均由浏览器直接保存到本地下载目录。

建议仅从可信来源获取代码，并在安装前自行检查扩展权限和源文件。
