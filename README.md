# 雨课堂课件批量导出

这是一个面向 `https://changjiang.yuketang.cn/` 的 Manifest V3 浏览器扩展。它复用网站已有的“课件 → 打印课件”数据与打印页面，将当前账号有权访问的课堂课件批量保存为 PDF。

## 安装

1. 在 Chromium 或 Edge 中打开扩展管理页面并开启“开发者模式”。
2. 选择“加载已解压的扩展程序”。
3. 选择本文件夹 `yuketang-courseware-exporter`。

## 使用

1. 登录长江雨课堂，并保持任意雨课堂标签页打开。
2. 点击扩展图标，选择“扫描课程”。
3. 勾选需要导出的课程，然后选择“批量导出为 PDF”。
4. 文件会保存到浏览器下载目录中的 `雨课堂课件/课程名/`。

## 说明

- 扩展仅调用登录账号本身可以访问的接口，不尝试绕过权限或内容保护。
- 网站现有导出流程实际生成的是打印版课件，因此本扩展输出 PDF，而不是原始可编辑的 `.pptx` 文件。
- 扩展使用 `chrome.debugger` 的 `Page.printToPDF` 能力自动完成“另存为 PDF”，安装时浏览器会显示相应权限提示。
- 导出期间请保持登录标签页与浏览器打开。课程较多时需要等待一段时间。
