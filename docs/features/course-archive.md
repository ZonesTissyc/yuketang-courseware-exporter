# 课程归档

> 状态：Beta。接口和交互已经实现，目前主要基于长江雨课堂验证。

## 功能定义

课程归档用于把旧课程从雨课堂首页移入“我的归档”。它不会下载或删除课程资料，也不会退出课程。归档后的课程可以在插件中恢复到首页。

入口为：`其他功能 → 课程归档`。

## 添加归档

页面默认使用时间关键词筛选课程：

1. 读取当前首页课程名称中的 `20xx春/夏/秋/冬` 关键词。
2. 找到时间最新的课程。
3. 自动选择上一教学学期。例如最新课程为 `2026秋`，默认关键词为 `2026春`；最新课程为 `2026春`，默认关键词为 `2025秋`。
4. 自动推导仅使用春、秋学期。夏、冬仍可由用户手动选择。

年份选择范围为当前年份至八年前，包含首尾年份。季度可选择春、夏、秋、冬。两个选择框会同步生成自定义关键词，例如 `2026` 与 `春` 会生成 `2026春`。

用户直接修改自定义关键词后，年份和季度选择框会清空，以自定义关键词为准。

点击“添加至我的归档”只筛选并展示命中的课程，不会立即归档。用户可以调整勾选结果，再点击“归档”并进行二次确认。

## 我的归档

“我的归档”页面读取当前账号已经归档的课程。点击单门课程旁的“恢复”，课程会重新显示在雨课堂首页。

## 接口

课程归档复用当前雨课堂页面的登录态：

| 接口 | 用途 |
| --- | --- |
| `GET /v2/api/web/courses/list?identity=2` | 获取首页课程 |
| `GET /v2/api/web/classroom_archive?user_id={用户ID}` | 获取归档课程 |
| `POST /v2/api/web/classroom_archive_set` | 归档或恢复课程 |

写操作的 JSON 参数为：

```json
{
  "classroom_id": 123456,
  "action": 1
}
```

`action: 1` 表示归档，`action: 0` 表示恢复。插件逐门执行写操作，因此单门失败不会阻止其他已选课程继续处理。

## 注意事项

- 归档会改变雨课堂账号中的课程展示状态。
- 操作前会展示匹配结果并要求用户确认。
- 插件不会自动定期归档课程，也不会保存自动归档规则。
- 其他雨课堂平台可能没有相同接口，失败时不会绕过平台限制。
