# 批量课件导出

> 状态：已实现

## 功能目的

复用雨课堂现有的“课堂回顾 → 课件 → 打印课件”流程，将当前账号有权访问的课件批量生成 PDF。导出的不是原始 PPT 或 PPTX 文件。

## 使用步骤

1. 登录任意受支持的雨课堂站点并打开页面。
2. 打开扩展，等待课程列表加载。
3. 搜索并勾选一门或多门课程。
4. 点击“导出 N 门课程”进入配置页面。
5. 设置日期范围。
6. 单门课程可以继续取消不需要的课件。
7. 选择现有的“雨课堂课件”目录并授权读写。
8. 选择宽容或严格重复处理模式。
9. 开始导出并等待任务完成。

## 扫描逻辑

课程列表来自：

```text
/v2/api/web/courses/list?identity=2
```

课堂活动来自：

```text
/v2/api/web/logs/learn/{classroomId}?actype=-1&page={page}&offset=20&sort=-1
```

插件最多读取 100 页，只保留 `type === 14` 且包含 `courseware_id` 的活动。同一次扫描中相同 `courseware_id` 只保留一次。

课堂回顾接口用于识别实际课件 ID：

```text
/api/v3/classroom-report/student/review?lesson_id={lessonId}
```

时间线中的 `presentationId` 或 `pres` 会转换成独立导出任务。去重键为“课程 ID + 课件 ID”，因此不同课程引用同一课件时仍各自保留一份。

## 日期和勾选过滤

- 起止日期都为空表示不限日期。
- 只填起始日期表示该日期及以后。
- 只填结束日期表示该日期及以前。
- 无法取得日期的课堂不会被日期条件排除。
- 单门课程支持逐个勾选；多门课程按日期范围导出全部匹配课件。

## PDF 生成

课件数据来自：

```text
/api/v3/lesson-summary/student/presentation?lesson_id={lessonId}&presentation_id={presentationId}
```

后台把幻灯片数据写入当前站点的 `localStorage.rain_print`，然后打开同一站点的 `/web/print`。打印页及图片加载完成后，通过 Chromium DevTools Protocol 的 `Page.printToPDF` 生成 PDF，并关闭临时标签页。

## 目录和文件名

用户选择“雨课堂课件”根目录，插件在其中创建课程子目录：

```text
雨课堂课件/
└── 课程名称/
    ├── 2026-09-01 第一次授课.pdf
    ├── 2026-09-08 第二次授课 - 课件 01 教学内容.pdf
    └── 2026-09-08 第二次授课 - 课件 02 课堂练习.pdf
```

- 单课件授课使用日期和授课名称；课件标题不同时附加课件标题。
- 多课件授课使用两位起步的序号。
- Windows 非法字符会替换为下划线。
- 单个目录段最多保留 100 个字符。

## 重复处理

### 宽容模式

最终文件名已经存在时直接跳过，不加载打印页，也不生成 PDF。适合日常增量导出。

### 严格模式

仍然生成 PDF，然后检查同名文件及其 `(n)` 变体：

- 任一文件大小与新 PDF 相同：跳过写入。
- 没有相同大小：写入下一个可用的 `(n)` 文件。
- 旧文件不会被覆盖。

## 取消和错误

取消采用协作式检查：扫描分页和逐个课件处理之间会检查取消标记，正在执行的单次网络请求或 PDF 生成不会被强制中断。

单个课件失败不会终止整个批次，错误会加入任务错误列表。目录权限失效、课程扫描失败等任务级错误会使任务进入 `error` 状态。

## 已知限制

- 无法恢复 PPT 动画、备注、字体和可编辑对象。
- 网站接口或打印页面变化后可能需要适配。
- 每个课件都需要完整加载图片，批量任务耗时与课件数量近似线性增长。
