# 平台兼容性

## 已识别域名

| 域名 | 显示名称 |
| --- | --- |
| `www.yuketang.cn` | 普通雨课堂 |
| `pro.yuketang.cn` | 荷塘雨课堂 |
| `huanghe.yuketang.cn` | 黄河雨课堂 |
| `changjiang.yuketang.cn` | 长江雨课堂 |

其他 HTTPS `*.yuketang.cn` 子域名统一显示为“雨课堂”。非 HTTPS 页面和相似但不属于 `yuketang.cn` 的域名不会被接受。

## 兼容性策略

当前功能基于长江雨课堂开发和测试。在其他雨课堂域名打开扩展时，顶部会显示：

> 本插件基于“长江”雨课堂开发，不保证在当前雨课堂能正常使用！

后台接口使用相对路径，打印页也使用当前标签页的 origin，因此其他平台可以复用相同流程；但各平台返回字段、接口权限或页面结构可能不同。

## 适配新平台

适配前需要确认：

1. 课程列表接口结构。
2. 课堂活动中的课件类型和 ID 字段。
3. 课堂回顾时间线字段。
4. 课件详情和幻灯片字段。
5. `/web/print` 是否存在并使用相同的 `rain_print` 数据。
6. 图片域名是否位于 Manifest 允许范围内。
