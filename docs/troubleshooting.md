# 常见问题排查

## 扫描不到课程

依次检查：

1. 当前标签页是否为 HTTPS `*.yuketang.cn` 页面。
2. 当前页面是否仍处于登录状态。
3. 网站自身是否能正常打开课程。
4. 扩展修改后是否重新加载。
5. 当前平台接口是否与长江雨课堂兼容。

## 目录无法使用

- 点击“重新授权”恢复读写权限。
- 如果目录已移动或删除，重新选择目录。
- 使用最新版 Chrome 或 Edge；不支持 File System Access API 的浏览器无法使用目录写入。
- 应选择“雨课堂课件”根目录，而不是某一门课程的子目录。

## 仍然出现重复文件

- 宽容模式只按最终目标文件名判断。
- 严格模式会比较同名和 `(n)` 文件的大小，但不会比较 PDF 内容哈希。
- 标题或日期变化会产生不同目标文件名，不会被视为同名文件。

## 打印页面或图片超时

确认网络稳定，并检查账号是否有权访问该课件。某些平台的打印页面结构不同，也可能导致就绪检测失败。

## 导出完成后仍显示旧状态

任务所属标签页刷新或跳转时，已经完成、失败或取消的状态会重置。正在运行的任务不会被清除。如果扩展版本刚更新，请在扩展管理页重新加载。

## 为什么不是 PPTX

网站的打印流程只提供课件页面和图片，扩展无法从中恢复原始动画、备注、字体和可编辑对象。
